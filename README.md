# NeuroLens

> Interactive visualizer for BERT, T5, and the transformer architecture.
> Built for the NUTECH NLP Lab (Lab 10 — Translation & Summarization).

NeuroLens is a single-page web app that makes transformer internals **visible**: tokenization, embeddings, attention heads, encoder/decoder blocks, and the architectural gap between BERT and T5 that's the answer to *"why can't BERT do translation?"*. Every diagram is hand-rendered SVG — there are no stock images, no icon fonts, and no emojis anywhere in the UI.

[https://github.com/AbdulGhani002/neurolens](https://github.com/AbdulGhani002/neurolens)

---

## What's inside

| # | Module | What you see |
|---|--------|---------------|
| 01 | **Architecture Explorer** | Toggle BERT / T5. Click any block (embedding, attention, FFN, layer-norm, etc.) and read what it computes, its formula, and where it sits in the stack. T5 view highlights the cross-attention arrow and autoregressive feedback loop that BERT lacks. |
| 02 | **Attention Visualizer** | 12 attention heads of a single encoder layer drawn as heatmaps. Click a head, then click a source token to see arc-style attention destinations and the top-4 attended tokens. Patterns match the families described in Clark et al. 2019 (diagonal, prev-token, [CLS]-sink, syntactic, broad-context, etc.). |
| 03 | **Tokenizer Playground** | Same sentence run through WordPiece, SentencePiece, and BPE side by side. Color-coded chips, continuation markers (`##`, `▁`, `Ġ`), vocab-hit stats. |
| 04 | **Embedding Space** | 2-D scatter of 50+ words by semantic category. Click a word to highlight its 5 nearest neighbours. Vector arithmetic demo: `king − man + woman ≈ queen` shown as arrows on the canvas. |
| 05 | **BERT vs T5** | One input, four tasks (sentiment, translation, summarization, NER). Two architectures, side-by-side outputs. Explicitly shows where BERT gives up. |
| 06 | **Why not BERT for generation?** | Animated step-by-step demo: T5 produces Urdu translation one token at a time; BERT produces the same number of 768-dim vectors and stops. Followed by the three missing pieces — causal mask, cross-attention, autoregressive loop — each with the formula. |

## Stack

- **Vite + React 18 + TypeScript** — single-page app, no backend required
- **Tailwind CSS** — custom dark theme with cyan/violet/coral/amber accent palette
- **Framer Motion** — page transitions and inline animations
- **React Router** — `/architecture`, `/attention`, `/tokenizer`, `/embeddings`, `/compare`, `/why-not-bert`
- **Pure SVG** — every diagram, chart, and brand mark is hand-drawn; no `<img>` tags for content

Custom brand mark, custom favicon, custom hero illustration. No third-party iconography, no stock photos.

## Pedagogical notes

The numerical data in this app is illustrative, not generated by a live model:

- **Attention matrices** are synthesized to match the head families found in real BERT checkpoints (diagonal, previous-token, sink-on-[CLS], syntactic-dependency-like, etc.). Patterns are recognizable; exact values are not from any specific run.
- **Tokenizer** implementations are simplified with a tiny built-in vocab. They reproduce the *shape* of each algorithm — continuation markers, longest-prefix rules — without shipping a 30k-token vocab file. For exact tokenization, use `transformers.AutoTokenizer`.
- **Embeddings** are hand-placed in 2-D so the semantic clusters and the gender-axis analogy are visible at a glance. Real embeddings live in 300–768 dimensions; what you see is a stylized PCA projection.

The goal is *understanding*, not reproduction.

## Lab context

This was built as the deliverable for **Lab 10 — Translation and Summarization using BERT and T5** in the NLP Lab course (AI-23 batch, NUTECH Islamabad). The lab's three learning objectives:

1. Understand transformer-based models (BERT and T5).
2. Perform text summarization and text translation using T5.
3. Explore why BERT is not directly used for generation tasks.

NeuroLens addresses all three by making the architecture and its behaviour *visible*. Modules 1–4 build intuition for transformer internals; modules 5–6 directly answer the BERT-vs-T5 question that the lab asks.
